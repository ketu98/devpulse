Privacy Policy for DevPulse

Effective date: September 5, 2026

DevPulse is a personal developer automation project created to generate and publish technical learning content related to software engineering, AI/GenAI, .NET, Azure, databases, and system design.

Information We Collect

DevPulse does not intentionally collect, sell, rent, or share personal information from users.

If DevPulse connects to a third-party service such as LinkedIn or GitHub, authentication and account information are handled through that service's official authorization mechanisms.

LinkedIn Data

When authorized by the account owner, DevPulse may use LinkedIn permissions solely to publish content on behalf of that authenticated LinkedIn member.

DevPulse does not use LinkedIn data for advertising, profiling, resale, or unrelated purposes.

GitHub Data

DevPulse may interact with its associated GitHub repository to create, update, validate, and publish technical content and code samples.

Data Storage

Authentication credentials, API tokens, and other secrets are intended to be stored using secure secret-management features such as GitHub Actions Secrets and are not intentionally committed to public source repositories.

Third-Party Services

DevPulse may interact with third-party services including GitHub, LinkedIn, and other public technical resources. Use of those services is governed by their respective privacy policies and terms.

Data Sharing

DevPulse does not sell or rent personal information.

Information is only transmitted to third-party services when necessary to provide an explicitly authorized integration or publishing function.

Data Retention

DevPulse does not intentionally maintain a separate database of personal user information. Authentication tokens or configuration values may be retained only for as long as required to operate authorized integrations.

Security

Reasonable technical measures are used to protect credentials and configuration, including avoiding storage of secrets in public repositories and using platform-provided secret storage where available.

Changes to This Policy

This Privacy Policy may be updated as DevPulse evolves. Material changes will be reflected in this document.
