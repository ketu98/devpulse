# Transactions in EF Core: Practical Guide\n\nThis repository demonstrates how to implement transactions in EF Core for backend services.\n\n## Prerequisites\n- .NET 6+ installed\n- SQL Server LocalDB configured\n\n## Setup\n1. Clone this repo\n2. Run `dotnet run` to execute the example\n3. The database will be created and dropped automatically\n\n## Usage\n- The `OrderService.ProcessOrder()` method shows a transaction wrapping order creation and inventory deduction.\n- It handles failures and rolls back changes.\n\n## Key Concepts\n- Transactions must be explicitly managed\n- Use `BeginTransactionAsync()` in async methods\n- Always handle exceptions and rollback\n\n## Limitations\n- Not suitable for long-running or distributed operations\n- Avoid in read-only or non-critical operations\n\n## Testing\n- Run the program to verify order and inventory state\n- Ensure data consistency after success or failure\n\n> This example is designed for clarity and correctness — not for production without additional validation.\n\n---\n\n*Note: This is an educational example. Do not use in production without proper auditing and logging.*
